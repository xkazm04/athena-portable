PositionThe bet, the target and the kill line

The bet: caregivers do not appeal because the evidence is spread across paper, phone calls and portals. Put it in one cited case and hand them a finished action to sign, and they will appeal.

Measurable target (pilot, 40 households, 90 days)

  • ≥ 50% of eligible denials found in the household's mail get an appeal filed, against the 11.5% MA baseline S
  • Median caregiver hands-on time ≤ 30 min per filed appeal, measured by the ledger's session clock A
  • 0 sentences in any signed packet without a source, by an independent citation audit

Kill line: the bet is wrong if

  • fewer than 30% of found denials are appealed even with the packet ready. The blocker would then be will, fear or authority, not evidence.
  • median hands-on time stays above 90 min. The senses would not be saving the work.
  • the audit finds any filed claim that its cited source does not support. The product is about proof, so one unsupported claim breaks it.

Hackathon-scale kill, before any pilot: on Athena's existing document-reading corpus (proving/docread, 90 paired documents), Muse Spark reading SAM crops must reach at least 90% of the Claude documents lane's field accuracy (96.2%, run 20261022T195808Z, measured on Claude, not on Meta). If it does not, the paper sense ships behind the existing reader and the demo says so.

MachineThe whole, on one page

The whole of Athena Portable survives, and the Meta models add what was missing. Three senses feed one cited brain. One gate stands between the case and anything irreversible. One ledger records every call, priced and tagged with its data class.

Machine · part 1Paper sense: one sweep of the kitchen table

The caregiver films the pile of mail for about 20 seconds, spreading envelopes with a hand. SAM 3.1 tracks each document through the video under one identity S. Athena picks the sharpest, flattest frame of each track and crops it to its mask. Muse Spark reads each crop into a structured episode. Each crop goes to Spark on its own, so an ad flyer's text never mixes with the denial's.

-- new: an evidence pointer every episode carries (extends core/brain episodes)
CREATE TABLE evidence (
  evidence_id   TEXT PRIMARY KEY,          -- ev_…, minted in contracts/ids.py
  episode_id    TEXT NOT NULL,             -- the episode it backs
  kind          TEXT NOT NULL,             -- 'frame_mask' | 'call_span' | 'page_capture'
  file          TEXT NOT NULL,             -- media under the case folder, on disk (invariant 1)
  frame         INTEGER,                   -- frame_mask: chosen frame
  track_id      INTEGER,                   -- frame_mask: SAM track identity
  bbox          TEXT,                      -- frame_mask: [x,y,w,h]
  mask_rle      TEXT,                      -- frame_mask: run-length mask
  t0_ms INTEGER, t1_ms INTEGER, speaker TEXT, -- call_span
  capture_id    TEXT,                      -- page_capture: existing captures table
  sha256        TEXT NOT NULL,             -- of the media, so a cite cannot silently drift
  created_at    TEXT NOT NULL
);

Machine · part 2Call sense: the insurer call, written down to the second

The caregiver puts the call on speaker by the PC or the phone. Athena first asks for consent and says it on the line ("this call is being transcribed for my records"), because about eleven US states require every party to consent to recording S. Muse Voice Transcribe streams diarized turns S. The case feeds the transcriber its own vocabulary through keyword biasing: claim numbers, the plan's name, drug and facility names. A reference number read out fast then comes through as the right string, not a near miss.

Fallbacks, because Muse Voice Transcribe is on Meta's API docs but on neither hackathon product list S: (a) Muse Spark 1.2 audio input, which Meta's model page recommends for audio S, used on 30-second chunks after the call, with no live hint; (b) the local whisper.cpp listener Athena already ships (channels/voice/whisper.py). Diarization quality on a speakerphone call is unverified. Day 1 of the build measures it.

Machine · part 3The case and its clock

A case is Athena Portable's existing case file (adopt/cases.py, a goal in the brain, ADR 0123) with one change: it is now about a person the caregiver acts for. Each notice opens a deadline. Each fact cites episodes. Muse Wonder gets the whole case in one context (letters, call turns, portal pages, about 100–300k tokens A, within its 1,048,576 S) and proposes the next action. The proposal goes through the gate like any other.

# goals/<proj>.md data block: the case, readable on disk (invariant 1)
case:
  id: proj_7f3a                      # minted once, kept across approvals (ADR 0123)
  acting_for: "Mom (Ruth)"           # new: the person the caregiver represents
  authority: { kind: "CMS-1696", evidence: ev_19c2 }   # R: appointment-of-representative form, itself cited
  playbook: observation-status-appeal   # existing chore, benched "exceeds" on Claude (synthetic world)
  notices:
    - { episode: ep_51d0, kind: denial, dated: 2026-10-14, window_days: 65, window_cites: ep_51d0 }
  facts:
    - { id: fct_a1, text: "Reference no. 4471-B", cites: [ep_call_0112] }
    - { id: fct_a2, text: "Stated reason: not medically necessary", cites: [ep_51d0] }
    - { id: fct_a3, text: "Discharge summary lists 3 skilled-nursing needs", cites: [ep_tab_mychart_08] }
  state: packet_ready

Machine · part 4The signed packet: you sign what you can check

Athena Portable's worst UAT finding was that the card did not show what the user was signing: one parameter, the recipient visible only in the model's rationale, no body (UAT 2026-10-01, D3: "Who is it going to? I do not know without opening the books"). For an appeal, the thing being signed is a document. So the gated action carries the whole packet: letter, exhibits and recipient. Every sentence in the letter is bound to the evidence ids it rests on, and the gate signs over a hash of all of it.

// new manifest field: a gated tool declares what its card must show (answers UAT D3)
{ "name": "submit_reconsideration",
  "reversible": false, "side_effects": "external",   // → GATED by HostTool.default_class
  "preview": { "document": "packet_id", "recipient": "plan_appeals", "as": "representative" },
  "binds":   ["sha256(packet)", "sentence→evidence map"] }

Machine · part 5The router and the ledger: one data policy, enforced per call

Meta's API has a feature most stacks lack: Contributor mode. Muse Spark costs 12.5× less on input ($0.10 against $1.25 per 1M tokens) if Meta may train on the prompts, files and responses S. For a parent's medical letters that is never acceptable. For the Proving Ground's synthetic worlds it is ideal. Athena makes this a structural rule, in the same way as her gate: a call's data class picks its model and mode, the model is never asked, and the ledger records which mode ran.

-- core/ledger.py: companion_turn gains two columns (one row per invocation stays the rule)
ALTER TABLE companion_turn ADD COLUMN api_mode   TEXT NOT NULL DEFAULT 'n/a'; -- 'standard' | 'contributor' | 'local'
ALTER TABLE companion_turn ADD COLUMN data_class TEXT NOT NULL DEFAULT 'personal'; -- 'synthetic' | 'personal' | 'sealed'
-- the audit a caregiver can run:  SELECT COUNT(*) FROM companion_turn
--   WHERE data_class != 'synthetic' AND api_mode = 'contributor';   → must be 0

Machine · part 6The household: one Athena, two people, one phone in the kitchen

Athena Portable already joins several computers and a phone into one Athena over Tailscale (peer/, ADR 0140). The phone is a small web app served by the PC (peer/phone.py, peer/mobile/) that answers cards. Athena Kin makes the phone her eyes and ears in the parent's home, and adds a second person: a sibling who can see the case and answer cards they were granted, but never the other person's approvals or spend. The overlay already keeps those apart. What is new is identity per person, not just per device.

Machine · part 7The Proving Ground on Muse: attack the senses, not just the tab

New senses mean new attack surfaces. A scam letter in the mail pile is a prompt injection on paper. A "representative" on the call can say "just approve the resubmission". Glimmer's own published AgentDojo attack-success rate is 28.4% S, and that is why the gate, not the model, must hold. The Gauntlet already proved this on browser surfaces: 306 hostile turns, 0 breaches, verdicts read off the gate's records (runs 20261007T140609Z, …205627Z, …213007Z, measured on Claude and Nemotron).

ArgumentThe demo: 2 minutes 45 seconds

One case, one evening. The caregiver is played by a teammate. The parent, the plan and the portal are a simulated world built from the existing observation-status-appeal playbook, and the video says so on screen. The camera, the call and the gate are real.

  1. 0:00Title card: "80.7% of appealed denials win. 11.5% are appealed." (KFF 2024). The voiceover: "This is why."recorded
  2. 0:12A kitchen table, six envelopes. The phone films a 20-second sweep. On the PC, six outlines appear and settle, one per document. The denial lights amber: "Reconsideration window: 65 days from Oct 14, read from the letter."live
  3. 0:45Athena opens the plan portal and MyChart in tabs. The discharge summary lists three skilled-nursing needs. Each becomes a fact with a small link icon pointing to its capture.live on a sandbox portal
  4. 1:15The lean-in moment. The caregiver calls the "plan" (a second teammate) on speaker. The transcript streams, Rep and Caregiver in two colours. The rep says the claim was denied because "records were never received". The halo pulses and the phone shows one line: "Your letter says 'not medically necessary'. Ask which reason is on file, and for a reference number." The caregiver asks. "4471-B." The fact appears, citing 01:12–01:19.live
  5. 1:55The packet. Muse Wonder's draft appears as a card. Hovering a paragraph highlights the exact crop of the denial letter, or plays the three seconds of the call it cites. A sentence with no source is never drafted, and the bench log shows one that was refused.live
  6. 2:15The caregiver signs on the phone. The packet goes to the sandbox portal once. A second tap on the same card is refused approval_spent.live
  7. 2:30The ledger: every call priced, tagged standard / personal, total for the case shown. Then one line: contributor calls with personal data: 0. Closing card: "Athena Kin. You sign what you can check."live numbers

Holds up live: every live beat has a recorded take of the same run, labelled "recorded on (date)" if it is used. The trigger for using it: an API call over 20 s or an error (the pattern Athena Portable already uses for its trigger page). No real insurer is contacted and no real appeal is filed. Live hint latency is unverified and is measured on day 4. If it is over ~3 s, the hint appears after the turn and the video says so.
