**Strengths that bind every build item (do-not-touch guardrails):** "Athena asks you first" before every gated action;
onboarding is short and always ends (median 2 cards); the rehearsal is labelled invented and a shaped rehearsal
withholds its dollar figure (ADR 0125); Runs receipts say where every number comes from. An honest label must not turn
into a disclaimer wall.

**Opposing verdicts:** none at the panel level - home and work Characters converged on the same two complaints.
Within a Character, the escalation from aside to judge voice ran one way: polite asides ("I wasn't sure where the
rehab bill comes from") became "I can't trace either number" in the verdict, which is why trust outranks clarity here.

## 3. Methodology lessons (folded into the overlay or the harness)
- **The judge must see the page, not the data.** It saw `promise` and the numbers row, so it criticised a long
  sentence the page does not show and an "Exceeds (n=1)" label that is not rendered: 37 refuted leads. Next run: give
  the judge the page's rendered text (a snapshot of the topic page per chore, from the desktop build or a node render
  of the view) instead of a reconstruction.
- **Research lanes were off in the harness** (`chores_uat/run.py`), so "(my guess)" counts may run high against
  production. The recertify run turns them on, or says it did not.
- **Case cards echo the example world** they were written from, so the harness under-measures world leakage; the
  next cards should be written from the Character first and the playbook's apps second.
- **The walkers' refuter pass paid for itself:** 37 of 331 leads refuted with file:line, and the scouts' hypothesis
  that the Value tile and "Worth" line disagree held only for month/week units - refuted in 6 areas, confirmed in 1.
- **Shared units worked:** honest-number ratios are comparable across ten parallel walkers (28-40%) because
  `rubric.md` defined NUMBER and HONEST NUMBER before the walk.
