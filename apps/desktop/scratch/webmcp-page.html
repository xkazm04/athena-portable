Scratchbox

A page with three WebMCP tools and nothing else, so the relay can be proved without a real application. scripts/smoke.mjs serves this file and asserts the one line the shell prints under ATHENA_SMOKE=1.

  • invoice_list — reversible, reads a list. The `athena` block says so.
  • invoice_send — external side effects, so the gate has one to refuse.
  • invoice_explode — throws, because a throw must be a result and not a dropped promise (protocol.md, "Requests").
